# GoPlay Tournament WB

WB এর Free Fire প্লেয়ারদের জন্য টুর্নামেন্ট প্ল্যাটফর্ম 🔥

## GoPlay কি?
GoPlay = গেমারদের নিজস্ব টুর্নামেন্ট বানানো + খেলার জায়গা। 
স্কোয়াড রেজিস্ট্রেশন, ম্যাচ শিডিউল, রেজাল্ট - সব এক জায়গায়।

## কিভাবে জয়েন করবা?
1. App ডাউনলোড করো
2. নাম + UID দিয়ে রেজিস্টার করো  
3. টুর্নামেন্ট জয়েন করে খেলা শুরু করো
